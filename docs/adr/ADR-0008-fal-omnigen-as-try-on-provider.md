# ADR-0008 — เลือก fal.ai (OmniGen V2) เป็นผู้ให้บริการ AI try-on จริง

**สถานะ:** ✅ Accepted · 2026-10-01

## บริบท

[ADR-0001](ADR-0001-2d-photo-try-on-on-twin.md) ตั้งใจห่อผู้ให้บริการ AI ไว้หลัง `TryOnAdapter` interface
เดียวตั้งแต่ต้น แต่ยังไม่เคยเลือกเจ้าจริง (ใช้ `mock` ตลอดช่วงพัฒนา) พอจะ deploy ขึ้น production จริง
(ดู WORKLOG "Deploy Vercel" 2026-10-01) ถึงเวลาต้องเลือก

ข้อจำกัดสำคัญที่ผู้ให้บริการต้องรองรับ:
- **webhook + ตรวจลายเซ็นได้** (ADR-0005 บังคับ "ตรวจลายเซ็นก่อนเชื่อ payload เสมอ")
- ชุดในแอปมีได้ถึง 3 ชิ้นพร้อมกัน (เสื้อ+ท่อนล่าง+ชั้นนอก หรือ เดรส+ชั้นนอก) ตาม `shared/outfit.ts`

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| FASHN (เจ้าเฉพาะทางลองเสื้อผ้า) | คุณภาพการลองชุดดีที่สุด เนียนสมจริง | รับได้ทีละ 1 ชิ้นต่อการเรียก 1 ครั้ง — ชุดที่มีมากกว่า 1 ชิ้น (เสื้อ+ท่อนล่าง) ต้องเรียก API ต่อเนื่องหลายรอบ (เอาผลรอบแรกมาเป็น input รอบสอง) เพิ่ม state/webhook ต่อ adapter เอง ซับซ้อนขึ้นมาก และไม่มีลายเซ็น webhook ให้ตรวจ (ต้องใช้ secret ใน query string แทน) |
| Replicate (IDM-VTON ฯลฯ) | มี webhook เซ็นลายเซ็นแบบ Standard Webhooks (HMAC) ดี | โมเดลที่มีส่วนใหญ่รับทีละ 1 ชิ้นเหมือน FASHN · บิลตามวินาที GPU คาดเดาต้นทุนยากกว่า |
| **OmniGen V2 ผ่าน fal.ai** ✔︎ | รับรูปได้สูงสุด 3 ใบ/ครั้ง (ท่า + ชิ้นเสื้อผ้าได้ถึง 2 ชิ้น) ในคำขอเดียว ไม่ต้องทำ state หลายรอบ · webhook เซ็นด้วย ED25519 + JWKS ตรวจได้จริง (ไม่ใช่แค่ secret ใน URL) · fal.ai เป็นเจ้ากลางที่เปลี่ยนไปใช้โมเดลอื่นในอนาคตได้ง่ายโดยไม่ต้องย้ายค่าย | เป็นโมเดล image-editing ทั่วไป (in-context generation) ไม่ได้เทรนมาเพื่อลองเสื้อผ้าโดยเฉพาะ — ความสมจริงของเนื้อผ้า/ทรงตัดอาจสู้ FASHN ไม่ได้ · รับได้สูงสุด 3 รูปรวมท่า เท่ากับชิ้นเสื้อผ้าได้จริงแค่ 2 ชิ้น |

## การตัดสินใจ

ใช้ **OmniGen V2 ผ่าน fal.ai** (`server/utils/try-on/fal-omnigen.ts`) เพราะตรงกับสถาปัตยกรรม
`TryOnAdapter` ปัจจุบันโดยไม่ต้องแก้ core flow เลย (ยังเป็น submit ครั้งเดียว → webhook ครั้งเดียวจบ)
และ **เลือกความเร็วในการเริ่มต้นมาก่อนคุณภาพสูงสุด** — ปรับเปลี่ยนเจ้าในอนาคตได้โดยไม่กระทบโค้ดอื่น
เพราะห่อไว้หลัง interface แล้วตาม ADR-0001

**ข้อจำกัดที่ยอมรับ:** ชุดที่มีครบ 3 ชิ้น (เสื้อ+ท่อนล่าง+ชั้นนอก) เกินโควตา 3 รูปของ OmniGen V2
(ท่า + เสื้อ + ท่อนล่าง = 3 รูปพอดีแล้ว) — `selectGarments()` จะตัด "ชั้นนอก" ออกจากภาพที่ส่งไปให้ AI
โดยอัตโนมัติ (ชั้นนอกยังถูกบันทึกเป็นส่วนหนึ่งของชุดในฐานข้อมูลตามปกติ แค่ไม่ถูกเอาไป render)

## ผลที่ตามมา

- `TryOnAdapter.parseWebhook()` เปลี่ยนจาก sync เป็น `Promise<TryOnResult> | TryOnResult` เพราะ fal.ai
  ต้องดึง public key (JWKS) มาตรวจลายเซ็นก่อน — กระทบแค่ `server/api/webhooks/try-on.post.ts` (เพิ่ม `await`)
- `NUXT_FAL_API_KEY` เป็น secret ใหม่ ต้องตั้งทั้งใน `.env` (dev) และ Vercel env vars (production)
- คุณภาพการลองชุดอาจไม่สมจริงเท่าเจ้าเฉพาะทาง — ถ้าฟีดแบ็กผู้ใช้แย่ ให้ทบทวนย้ายไป FASHN (ต้องออกแบบ
  sequential-call state เพิ่ม ดูหัวข้อ "ทบทวนเมื่อไหร่")

## ทบทวนเมื่อไหร่

ถ้าคุณภาพรูปที่ได้ไม่น่าพอใจ (สัดส่วน/เนื้อผ้าเพี้ยนบ่อย) ให้พิจารณาย้ายไปเจ้าเฉพาะทาง (FASHN/IDM-VTON)
โดยออกแบบให้ adapter จัดการ multi-step call ภายในตัวเอง (ซ่อนความซับซ้อนไว้หลัง interface เดิม ไม่ต้องแก้
`lifecycle.ts`) หรือถ้าในอนาคต fal.ai เพิ่มโมเดลลองเสื้อผ้าเฉพาะทางที่รับได้มากกว่า 1 ชิ้นต่อครั้ง ให้ย้ายมาใช้แทน

## แก้ไขเพิ่มเติม [2026-10-02] — เขียนโค้ดเสร็จแต่ยังไม่เปิดใช้งาน

ลืมคิดเรื่อง **ต้นทุนจริงต้องจ่ายเงินตั้งแต่ครั้งแรก** ไปตอนตัดสินใจ — fal.ai ไม่มีเครดิตฟรีให้บัญชีใหม่เลย
(ต่างจาก Replicate ที่มีรายงานว่าให้ ~$5-10 ตอนสมัคร) ผู้ใช้ทดสอบจริงแล้วเจอ `403 Forbidden: Exhausted
balance` ทันที (ยืนยันว่าโค้ด/การเชื่อมต่อถูกต้องสมบูรณ์ แค่ไม่มีเครดิต) และตัดสินใจไม่อยากจ่ายเงินตอนนี้

**สถานะปัจจุบัน:** โค้ด `fal-omnigen.ts` ทำงานถูกต้อง (ยืนยันแล้วว่าต่อ fal.ai สำเร็จจริง) แต่
`NUXT_TRY_ON_PROVIDER` ใน `.env` และ Vercel ยังเป็น **`mock`** ต่อไปตามคำขอผู้ใช้ — ไม่ได้ลบโค้ดทิ้ง
เก็บไว้พร้อมเปิดใช้ทันทีที่พร้อมจ่ายเงินจริง (แค่เปลี่ยนค่า env ตัวเดียว ไม่ต้องเขียนโค้ดใหม่)

สำรวจทางเลือกฟรีเพิ่มเติมแล้วไม่พบตัวที่ใช้งานได้จริง: Hugging Face public Space (Kolors VTON) ฟรีจริง
แต่รันบน CPU ช้ามาก (นาทีต่อรูป) ไม่เหมาะเป็น backend ของแอปจริง · Google Nano Banana ถูกกว่า fal.ai
(~$0.039/รูป) แต่ก็ไม่มีแผนฟรีเหมือนกัน — สรุปว่า**ไม่มีผู้ให้บริการ AI ลองเสื้อผ้าคุณภาพใช้งานได้จริงที่ฟรี
100% เลย** ถ้าจะลองแบบจ่ายน้อยที่สุดก่อนตัดสินใจจริงจัง ตัวเลือกที่ใกล้เคียงคำว่าฟรีที่สุดคือสมัคร Replicate
เอาเครดิตฟรีตอนสมัครมาใช้ก่อน (ต้องรับข้อจำกัดเดิม — โมเดลส่วนใหญ่บน Replicate รับได้ทีละ 1 ชิ้น)

**สำรวจรอบ 2 [2026-10-02]:** ผู้ใช้ถามหาทางฟรีอีกรอบ เจอข้อมูลจากเว็บรีวิวบุคคลที่สามว่า "Segmind ให้ฟรี 100
ครั้ง/วัน" — เช็คหน้า pricing จริงของ Segmind เองแล้วพบว่า**ไม่จริง** ต้องเติมเงินขั้นต่ำ $10 ก่อนใช้งานได้
เหมือนเจ้าอื่น (บทเรียน: ข้อมูล "ฟรี" จากเว็บรีวิว/aggregator บุคคลที่สามเชื่อไม่ได้ ต้องเช็คหน้า pricing
ทางการของผู้ให้บริการเองเสมอ) — ยืนยันซ้ำว่าไม่มี provider ไหนฟรีจริงเลย ทางเลือกที่เหลือสำหรับคนไม่อยากจ่าย
เงินเลยคือรันโมเดลโอเพนซอร์สเอง (ต้องมี GPU) หรือ Google Colab ฟรี (ไม่เหมาะกับแอปจริง ไม่เสถียร session
หลุดบ่อย) — ผู้ใช้เลือก**ใช้ `mock` ต่อไปก่อนเหมือนเดิม** ไม่ลองทางไหนเพิ่มตอนนี้
